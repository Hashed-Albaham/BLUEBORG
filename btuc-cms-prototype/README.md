# BTUC CMS Studio — النسخة التجريبية

نسخة تجريبية مستقلة لتطوير إدارة المحتوى لموقع شركة البرج الأزرق المتحدة. توفّر واجهة عامة مطابقة للنسخة الحالية، ولوحة إدارة على المسار `/admin` لإدارة الصفحات والمنشورات والقوالب والوحدات القابلة للترتيب.

## التشغيل المحلي

يتطلب المشروع Node.js 22+ وpnpm 10+.

```bash
pnpm install
pnpm dev
```

افتح `http://localhost:3000/admin` للوصول إلى لوحة الإدارة. تحفظ النسخة التجريبية التغييرات محليًا في المتصفح، ما يسمح باختبار إضافة الصفحات والوحدات وترتيبها قبل ربط قاعدة البيانات.

## الفحص والبناء

```bash
pnpm check
pnpm build
pnpm start
```

## الربط مع PHP/MySQL

مجلد `php-api` يحتوي على مخطط MySQL وخدمة PHP مرجعية. على استضافة PHP 8.2+ وMySQL 8.0+/MariaDB 10.6+، انسخ `php-api/config.example.php` إلى `php-api/config.php` ثم حدّث بيانات الاتصال وعنوان لوحة الإدارة المسموح به. بعدها أضف عنوان الخدمة في ملف `.env`:

```bash
VITE_CMS_API_BASE_URL=https://cms.example.com/api
```

تتعامل طبقة العميل مع ثلاث واجهات: `GET /health`، و`GET /content`، و`PUT /content`. لا تفعّل مسار الحفظ للإنتاج قبل إضافة مصادقة وصلاحيات مستخدمين وسجل تدقيق.

## البنية

| المسار | الغرض |
|---|---|
| `client/src/pages/AdminStudio.tsx` | لوحة الإدارة ومحرر الوحدات |
| `client/src/lib/cmsStore.ts` | نموذج المحتوى والتخزين المحلي التجريبي |
| `client/src/lib/phpClient.ts` | عميل REST المهيأ لخدمة PHP |
| `php-api/` | مخطط MySQL وخدمة PHP مرجعية |
