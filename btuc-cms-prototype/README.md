# BTUC CMS Studio — النسخة التجريبية

نسخة تجريبية مستقلة لتطوير إدارة المحتوى لموقع شركة البرج الأزرق المتحدة. توفّر معاينة عميل مؤسسية وهوية بصرية متسقة، ولوحة إدارة على المسار `/admin` لإدارة الصفحات والمنشورات والقوالب والأقسام القابلة للترتيب.

## مكتبة الصفحات والتحرير

عند اختيار «صفحة جديدة»، يستطيع المدير أو المحرر البدء بقالب صفحة متكامل: **الصفحة الرئيسية، من نحن، الخدمات، قطاعات العمل، المشاريع، دراسة حالة مشروع، القدرات التنفيذية، الأسئلة الشائعة، أو التواصل**. كل قالب ينشئ مجموعة أقسام مؤسسية قابلة للتحرير؛ يمكن إضافة أي قسم أو حذفه أو إخفاؤه أو نقله، كما يمكن تعديل عنوانه ووصفه وصورته من داخل الصفحة نفسها.

تحتوي إعدادات الصفحة على عنوان ومسار وخيار «إظهارها في ترويسة الموقع بعد النشر». تظهر الصفحة في قائمة العميل تلقائيًا فقط إذا كانت منشورة ومفعلة في الترويسة، ولا تظهر المسودات أو الصفحات المعطلة أو المحذوفة للزائر.

يمكن أن يضيف كل قسم، عند الحاجة فقط، **شرحًا للصورة** و**نص زر** و**رابطًا داخليًا أو خارجيًا**. تظل هذه الحقول اختيارية؛ لا يظهر الشرح أو الزر للزائر عندما تبقى فارغة. الروابط الداخلية في المعاينة تفتح صفحة CMS المنشورة المقابلة تلقائيًا.

## مكتبة الصور

تتيح المكتبة رفع الصور وتعديل الاسم والوصف النصي والتصنيف، ثم اختيار الصورة من خصائص أي قسم. عند محاولة حذف صورة مرتبطة بأقسام، تطلب اللوحة اختيار صورة بديلة أولًا لحماية مراجع الصفحات. تستخدم النسخة التجريبية تخزين المتصفح؛ لذلك يقبل الرفع المحلي صورًا صغيرة فقط (حتى **350 كيلوبايت**) لتجنب امتلاء مساحة المتصفح. في الإنتاج، يجب نقل الملفات إلى S3 أو التخزين المخصص في خادم PHP، لا إلى `localStorage`.

## التشغيل المحلي

يتطلب المشروع Node.js 22+ وpnpm 10+.

```bash
pnpm install
pnpm dev
```

افتح `http://localhost:3000/admin` للوصول إلى لوحة الإدارة. تحفظ النسخة التجريبية التغييرات محليًا في المتصفح، ما يسمح باختبار إضافة الصفحات والوحدات وترتيبها قبل ربط قاعدة البيانات.

## الفحص والبناء

```bash
pnpm check
pnpm test
pnpm build
pnpm start
```

## الربط مع PHP/MySQL

مجلد `php-api` يحتوي على مخطط MySQL وخدمة PHP مرجعية. على استضافة PHP 8.2+ وMySQL 8.0+/MariaDB 10.6+، انسخ `php-api/config.example.php` إلى `php-api/config.php` ثم حدّث بيانات الاتصال وعنوان لوحة الإدارة المسموح به. بعدها أضف عنوان الخدمة في ملف `.env`:

```bash
VITE_CMS_API_BASE_URL=https://cms.example.com/api
```

تتعامل طبقة العميل مع ثلاث واجهات: `GET /health`، و`GET /content`، و`PUT /content`. لا تفعّل مسار الحفظ للإنتاج قبل إضافة مصادقة وصلاحيات مستخدمين وسجل تدقيق.

## البنية

| المسار | الغرض |
