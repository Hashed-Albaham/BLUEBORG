# خدمة PHP/MySQL للوحة BTUC CMS

انسخ `config.example.php` إلى `config.php` وضع بيانات اتصال MySQL الصحيحة، ثم استورد `schema.sql` إلى قاعدة البيانات. عيّن متغير الواجهة `VITE_CMS_API_BASE_URL` إلى عنوان هذا المجلد بعد نشره على استضافة PHP 8.2+.

توفّر الخدمة نقاط `GET /health` و`GET /content` و`PUT /content`. قبل النشر الإنتاجي، أضف مصادقة جلسات وصلاحيات مستخدمين وسجل تدقيق، ولا تفتح مسار الحفظ للعموم.
