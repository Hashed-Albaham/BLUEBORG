# قائمة تنفيذ موقع البرج الأزرق المتحدة

- [x] تدقيق المصطلحات العربية وتوحيد «المشاريع» في الواجهة العامة.
- [x] إزالة إشارات وروابط وأيقونات الطرف الثالث من صفحة الموقع العامة.
- [x] تدقيق ملفات المشروع والاعتمادات لضمان عدم وجود مراجع عامة لطرف خارجي في النسخة المعروضة.
- [x] استبدال شعار النطاق القياسي برمز الشركة وتدقيق بيانات التعريف.
- [x] تقليل حمل الخطوط وتحسين المؤشرات التقنية ذات التأثير على الأداء.
- [x] فحص البناء والعرض وحفظ النسخة المنقحة.

- [x] استخراج الأنشطة المعتمدة من جميع الصور وتنظيمها في نطاقات خدمات قابلة للفهم.
- [x] إنشاء صورة بصرية أصلية متخصصة لكل نطاق خدمة رئيسي.
- [x] بناء الصفحة الرئيسية بهوية مؤسسية ومحتوى عربي احترافي.
- [x] تصميم أقسام الخدمات بتدرج معلوماتي واضح وروابط وصول مباشرة.
- [x] تنفيذ تنقل متجاوب، زر اتصال، وروابط بريد وموقع تعمل فعليًا.
- [x] تطبيق حركات هادئة وسريعة مع دعم تقليل الحركة وإتاحة لوحة المفاتيح.
- [x] مراجعة العرض على سطح المكتب والجوال ومعالجة الملاحظات البصرية.
- [x] فحص البناء النهائي وحفظ نسخة مكتملة قابلة للاستعراض.

- [x] إنشاء لوحة تحكم مستقلة لإدارة المحتوى التجريبي.
- [x] إضافة إدارة الصفحات والمنشورات والقوالب والوحدات.
- [x] دعم ترتيب الوحدات وتعديل بياناتها وحفظها محليًا في المتصفح.
- [x] تضمين عميل PHP REST ومخطط MySQL للتكامل المستقبلي.
- [x] توثيق التشغيل واختبار بناء النسخة التجريبية.
- [x] توحيد القوالب مع أقسام موقع BTUC الأساسية السبعة وإدارة المكتبة الإعلامية.
- [x] إضافة دخول تجريبي بأدوار مدير ومحرر ومراجع مع إدارة مستخدمين للمدير.
- [x] إضافة استعادة آمنة لآخر نسخة وإدارة كاملة للمنشورات.
- [x] اختبار مسارات النشر والتعطيل ومعاينة العميل وتجاوب الهاتف، إضافة إلى فحص الوحدات والأنواع والبناء.
- [x] تحليل المرجع البصري الجديد واستخراج نظام الأقسام والتباين والتسلسل البصري المطلوب.
- [x] إعادة تصميم معاينة العميل لتستخدم قوالب متصلة مطابقة للهوية المرجعية بدل التخطيط العام الحالي.
- [x] جعل الصفحات المضافة من الإدارة ترث القوالب الاحترافية نفسها مع تنويعات محتوى مناسبة لكل صفحة.
- [x] اختبار القوالب المعاد تصميمها على الهاتف وسطح المكتب وربطها بإنشاء الصفحات والنشر.
- [x] إنشاء مكتبة قوالب صفحات متكاملة: الرئيسية، من نحن، الخدمات، المشاريع، تفاصيل مشروع، والتواصل.
- [x] جعل كل قالب قابلًا لإضافة الأقسام وحذفها وإخفائها وترتيبها وتحرير نصوصها وصورها من داخل الصفحة ذاتها.
- [x] إضافة إعداد ظهور الترويسة لكل صفحة منشورة وتوليد روابط الصفحات المنشورة تلقائيًا ضمن القائمة الرئيسية.
- [x] تحليل التصميم الحي للموقع المرجعي وتطبيق نظامه البصري على معاينة العميل بدل تخطيط البطاقات الحالي.
- [x] إعادة بناء القوالب لتستخدم التكوينات البصرية المتنوعة نفسها للموقع المرجعي، بما في ذلك الأقسام والصور والتقسيمات.
- [x] إضافة تعديل بيانات الصورة داخل المكتبة: الاسم، الوصف النصي، والتصنيف.
- [x] إضافة حذف وسائط آمن مع منع حذف صورة مستخدمة أو استبدال مرجعها بصورة بديلة.
- [x] اختبار رفع الصورة وتعديلها وحذفها واستبدالها وربطها بالأقسام، مع مراجعة العميل على الهاتف وسطح المكتب.
- [x] إضافة قوالب صفحات مؤسسية جديدة تشمل قطاعات الخدمات، سجل المشاريع، دراسة حالة موسعة، الأسئلة الشائعة، وفريق/قدرات التنفيذ.
- [x] إضافة أقسام محتوى احترافية متوافقة مع هوية الموقع: شريط المسار، مبادئ التنفيذ، مؤشرات المشروع، معرض صور متدرج، دعوة إجراء، وأسئلة شائعة.
- [x] اختبار إنشاء كل قالب وإضافة كل قسم وحذفه وترتيبه وتعديله قبل مزامنة التحديث النهائي.
- [x] إضافة حقول اختيارية لشرح الصورة ونص الزر ورابطه وموضع الشرح داخل كل قسم.
- [x] إخفاء الشرح والزر والرابط تلقائيًا من واجهة العميل عند ترك الحقول الاختيارية فارغة.
- [x] اختبار روابط داخلية وخارجية لأزرار الأقسام والصور مع تحقق من صحة المسار قبل العرض للزائر.
