- [x] إزالة إشارات وروابط وأيقونات الطرف الثالث من صفحة الموقع العامة.
- [x] تدقيق ملفات المشروع والاعتمادات لضمان عدم وجود مراجع عامة لطرف خارجي في النسخة المعروضة.
- [x] استبدال شعار النطاق القياسي برمز الشركة وتدقيق بيانات التعريف.
- [x] تقليل حمل الخطوط وتحسين المؤشرات التقنية ذات التأثير على الأداء.
- [x] فحص البناء والعرض وحفظ النسخة المنقحة.

- [x] استخراج الأنشطة المعتمدة من جميع الصور وتنظيمها في نطاقات خدمات قابلة للفهم.
- [x] إنشاء صورة بصرية أصلية متخصصة لكل نطاق خدمة رئيسي.
- [x] بناء الصفحة الرئيسية بهوية مؤسسية ومحتوى عربي احترافي.
- [x] تصميم أقسام الخدمات بتدرج معلوماتي واضح وروابط وصول مباشرة.
- [x] تنفيذ تنقل متجاوب، زر اتصال، وروابط بريد وموقع تعمل فعليًا.
- [x] تطبيق حركات هادئة وسريعة مع دعم تقليل الحركة وإتاحة لوحة المفاتيح.
- [x] مراجعة العرض على سطح المكتب والجوال ومعالجة الملاحظات البصرية.
- [x] فحص البناء النهائي وحفظ نسخة مكتملة قابلة للاستعراض.

- [x] إنشاء لوحة تحكم مستقلة لإدارة المحتوى التجريبي.
- [x] إضافة إدارة الصفحات والمنشورات والقوالب والوحدات.
- [x] دعم ترتيب الوحدات وتعديل بياناتها وحفظها محليًا في المتصفح.

- [x] توثيق التشغيل واختبار بناء النسخة التجريبية.
- [x] توحيد القوالب مع أقسام موقع BTUC الأساسية السبعة وإدارة المكتبة الإعلامية.
- [x] إضافة دخول تجريبي بأدوار مدير ومحرر ومراجع مع إدارة مستخدمين للمدير.
